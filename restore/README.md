# Restore

## Zweck

Dieses Verzeichnis enthält Wiederherstellungsabläufe für Daten, Dienste und vollständige Systeme.

## Einstieg

Hier werden Datenbank-, Volume-, Service- und Full-Rebuild-Restores sowie deren Validierung dokumentiert und automatisiert.

## Abgrenzung

Die Erstellung von Sicherungen gehört nach `backup/`. Restore-Verfahren müssen unabhängig prüfbar bleiben.

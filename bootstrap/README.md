# Bootstrap

## Zweck

Dieses Verzeichnis enthält die idempotente Erstbereitstellung und Grundhärtung neuer Server.

## Einstieg

Hier werden Betriebssystem-Baseline, Benutzer, SSH, Firewall, Basispakete, Zeitsynchronisation und Container-Runtime vorbereitet.

## Abgrenzung

Anwendungskonfiguration und Service-Deployments gehören in `configuration/` beziehungsweise `deployment/`.

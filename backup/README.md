# Backup

## Zweck

Dieses Verzeichnis enthält die automatisierte Erstellung, Verschlüsselung, Übertragung und Prüfung von Backups.

## Einstieg

Hier liegen Backup-Jobs, Datenbank- und Volume-Sicherungen, Retention-Regeln, Offsite-Transfer und Verifikationslogik.

## Abgrenzung

Backup-Daten und Schlüsselmaterial werden nicht versioniert. Wiederherstellungslogik gehört getrennt nach `restore/`.
